- 已知客户端模板局部清理身份，用户 SOUL、项目规则和工具执行约束保留。
- 工具采用官方受约束参数视图与完整 MCP/JSON 兼容声明，保存完整原 Schema，往返恢复原名、参数、调用 ID、结果及媒体。
- 固定模型名称决定思考档位；目录能力、图片模型解析及账号实际选择保持关联。
- OAuth 已按实抓证据接入 PKCE、请求字段、首次初始化及操作轮询；认证使用独立 Go HTTP/2，模型传输继续使用原有 HTTP/1.1 配置。
- 账号粘性、权重、额度保护及恢复条件保留；所有请求统一选号，工具历史不构成账号准入条件，旧凭据目录不扫描。本地原生投影仅作匹配时可复用的转换缓存；无缓存仍按 agent 历史转换发送，上游上下文错误交回 agent。默认 `legacy` 策略不执行隐藏式断流续聊，保留正常传输重试及已交付流不跨账号拼接的边界。
- 转换错误保留正确 HTTP 错误类型，不误判为账号额度或健康故障；复杂结构化输出从首请求携带完整约束，合法 JSON null 正确处理。
- 普通上传文件的内容下载与元数据、推理引用采用相同鉴权和凭据作用域；生成图片继续提供原有公开结果 URL。
- 两种协议及流式末事件保留正常完成、截断和过滤状态；完整 JSON 根参数、重复调用 ID、SSE 分帧和内部生图结束边界已修复。
- 完成审计补齐停止序列转发、未知语义内容和工具类型的明确拒绝，以及账号重新检测的正常终止校验。修复看板前端仍校验旧 OAuth 路径导致授权链接为空，并给授权脚本加入内容版本标识。
- 按新增官方发包证据修正内部生图的同账号 trajectory／步骤延续和结果路径文本；同步 `generateContent` 改为 Content-Length，流式请求继续保持原分帧，六平台原生组件已重建并核验。内部 `generate_image` 现使用工厂对象身份验证的官方原名和完整参数声明；客户端同名工具不能伪装成内部服务。
- 独立 Messages 服务器搜索请求已接入官方搜索辅助模型：一次逻辑请求仅一次生成，返回真实来源链接和上游原摘要，准确报告实际 helper 模型与用量；不抓网页、不生成引文、不增加规划或总结调用。搜索保留额度/权重/健康判断，不重绑或延长主模型粘性。
- 搜索结果使用本地持久化密钥签发的 metadata-only receipt，支持同一 API 客户端回传历史并拒绝篡改、跨作用域借用；不声称持有网页正文或官方私有签名。未使用的引文生成和结果域名筛选代码已移除。
- 生图遇到明确 `QUOTA_EXHAUSTED` 且附有效恢复时间时，立即保留原始 429 和完整诊断交给账号池，避免同账号换主机重试后由网络错误覆盖额度语义。模型冷却、健康、原会话粘性和可用备用账号规则保持；普通 429／5xx 仍按原策略处理。
