# agy 上游指纹复刻：实施与验收

目标：Antigravity / Cloud Code 通道在对话、工具往返、多轮上下文、会话恢复、并发及重试中复用实测 agy 的网络与请求特征。客户端协议、账号轮询以及 Gemini App 两条通道保持兼容。不能用单元测试通过替代真实上游抓包验收。

2026-10-20 用户澄清后的当前边界：目标是 agent 请求与 agy 上游表达之间的双向转换，不是重做 agy 的任务调度/错误恢复状态机，也不以 Google 内部不可区分或任意网络边界穷举作为完成条件。工具名、参数和已识别固定框架可以转义；真实业务指令、权限、文件内容和实际能力不能损失。未知工具继续兼容，不能只凭同名冒充能力等价。必要生图声明保留；不新增无用途的网关身份或能力。网络失败由 agent 决定如何继续，网关只保留原有必要传输/鉴权/账号调度行为；不强制续旧任务，不补造恢复 user，不拒绝有完整上下文的新请求。以下早期实验是历史证据，冲突时以本段及最新实现记录为准。

后续验收以有限的功能链路为主：已识别客户端的工具声明→上游调用→客户端执行→真实回执→后续对话；普通上下文、完整历史/新上下文及重启；未知工具/自定义工具/能力冲突的兼容；原账号池、轮询、额度、看板、媒体和 Gemini App 路由的回归。断流只作职责边界的代表性检查，不再穷举九次故障、所有时点和随机退避来复制 agent 决策。
