# 2.0.1 审计修复说明

本次迭代对应 2026-11-07 对 2.0.0 工作区的健壮性审计。安装命令、默认端口、账号文件位置、模型名称档位规则和统一账号调度保持；不添加客户端工具执行、上下文管理或历史账号绑定。

## Schema 执行预算

HTTP 请求声明、历史工具参数、上游工具结果和结构化输出的 Schema 编译与校验全部在有容量限制的 worker 线程中执行。保留 Ajv 的 draft-07、2019-09、2020-12 及格式校验语义，不通过忽略 `pattern` 或降低工具约束来规避问题。离线转换测试的同步接口与生产异步入口共享转换步骤，HTTP 作用域会直接拒绝同步编译或同步 validator 调用，避免未来误接入重新打开主线程阻塞路径。

默认最多两个 worker；每个 worker 的老生代堆上限 64 MiB。Schema 上限 1 MiB、单次待校验参数上限 4 MiB、结构深度上限 64；排队最多 64 项、合计 16 MiB，排队上限两秒。编译预算一秒，进入参数匹配阶段后另设 250 毫秒预算。线程即使需要先编译未缓存的 Schema，也不会占用参数匹配预算。

超过执行预算时真正终止该线程，待终止完成后才释放容量并按需补位；请求取消和关闭也清理对应工作。输入超限或执行超时作为转换错误返回，不触发账号健康隔离或额度冷却；队列容量不足返回 503。异常请求受限时，另一条正常请求仍能被处理。

## 账号状态和凭据

账号记录新增授权代次 `grantGeneration`。没有该字段的旧记录使用稳定的兼容标识，在后续保存时保留同一授权身份；普通 token 刷新不等同于重新授权。刷新完成时核对当前授权，仅合并 token、有效期等允许字段，不能覆盖用户同期修改的启停、权重或新授权。

同一授权在账号池 reload 后保留稳定的 entry 对象，因此在途结果仍能更新当前路由使用的健康状态。授权替换后，旧 provider 失去持久化资格；旧请求的健康、冷却、目录及粘性更新不能污染新授权。请求处理继续使用原有轮询和故障切换规则。

POSIX 账号目录明确使用 0700、临时和最终凭据文件使用 0600，读取已有记录时兼容收紧权限。凭据路径不接受符号链接。Windows 使用单独的用户 DACL 保护逻辑，不能将 POSIX mode 位视为 Windows 权限保证。

## 上传和生成结果

HTTP 上传的 JSON、multipart 都不能设置保留用途 `generated`。客户端传入的来源、公开性和摘要字段不会成为信任依据。公开生成图片由内部生成保存入口创建，保存服务端来源、公开标志和内容摘要，并检查图片格式签名；下载时再次核对类型与摘要。

新生成图片的公开链接继续支持 GET/HEAD。普通上传仍需 API 鉴权和文件作用域。HTML、SVG 等内容使用附件下载，并设置 sandbox CSP 和 nosniff 响应头。

旧文件不删除、不迁移。旧版 `purpose=generated` 可能由上传方填写，不能自动赋予可信来源；因此旧公开链接收紧为需要原 API key 和作用域访问。这是本次必要的兼容行为变化。

## 本地媒体路径

所有 HTTP 入口默认关闭服务器本地路径读取，包括 `file_path` 与 `file://`，不按监听地址或代理连接的 loopback 地址判断信任。远程客户端可上传其本机文件后使用 `file_id`，内联内容和已有受限远程 URL 方式继续保留。

可信本机媒体流程可显式配置：

```bash
export ANTIGRAVITY_GATEWAY_MEDIA_LOCAL_PATHS=1
export ANTIGRAVITY_GATEWAY_MEDIA_ALLOWED_ROOTS='["/absolute/media-dir"]'
```

开启时必须提供非空绝对目录数组；服务配置保存沿用已有环境变量机制。读取时核对真实路径、允许目录及文件句柄，拒绝符号链接越界；网关配置目录、常见凭据目录和凭据文件仍被排除。允许目录应专用于媒体资料。

## 请求错误

JSON 语法有效但顶层不是对象的请求，例如 `null`、数组或字符串，返回 400 `invalid_request_body`。上传保留用途返回 400 `reserved_file_purpose`；受限本地路径返回 403 `media_local_path_not_allowed`。

## 验证边界

本次验证使用隔离数据目录、合成凭据和 mock 上游，回归账号竞态、文件权限、HTTP 鉴权和媒体兼容性。正式账号池、服务配置及服务器凭据不参与缺陷复现。Schema 并发存活测试保留真实 HTTP 入口及 `sendInSession`，只替换账号数据和上游网络，同时禁止主线程 Ajv 编译；另验证误接入同步函数会被 HTTP 边界直接拒绝。原审计脚本的 mock 硬调用旧同步 builder，不能替代本次生产异步调用链的验证。实际测试计数、源码摘要和安装包摘要随本次修复验收记录保存。

Windows DACL 的命令构造和调用契约可在本机测试，实际 Windows 权限行为需在 Windows 主机验收。未修改原生 Go 传输实现；多平台产物摘要检查不等于重新构建或所有平台运行验证。
