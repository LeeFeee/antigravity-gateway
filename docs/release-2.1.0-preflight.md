macOS 和 Linux 已完成真实 npm 全局安装、旧版 → 候选版 → 旧版演练，每阶段检查持久数据、账号信息、粘性/额度/用量/媒体/历史、服务路径及原端口约定。演练使用隔离合成数据，不算真实上游验收，也没有切换正式服务。

## 明确保留的边界

- Gemini 只提供 Task 的 Hydrogen/Argon Low 及相应别名；不接聊天模式，不提供未经验证的 High/Medium 档位。
- Gemini 任务多模态暂缓；原 Antigravity 图片生成、编辑及视频能力保留。
- 原生首次登录弹窗、条款确认与“不参加改进计划”选项的完整对应验证按用户决定暂缓。现有初始化/偏好接口证据与该缺口分别记录，不合并为“全部首次初始化已通过”。
- Linux Hermes 曾完成工具调用但漏写文件末尾换行，原样任务复测才通过；失败样本保留，不在网关中补写工具参数。一次私有并发验收目录冲突的批次已全部作废并重测。
- 搜索返回真实元数据、链接和模型摘要；不抓取网页，不声称拥有网页原文，不支持无法等价执行的离线、严格域名过滤和位置合同。
- 上游延迟尚未优化；通过记录中的耗时是实测，不承诺所有模型、账号、客户端及请求都具有相同延迟或成功率。

所有完整私有请求、SOUL、凭据、安装/回滚日志和失败证据保存在仓库外受限目录。最终代码回归 **1191 项通过、0 失败**，**103 个运行时及脚本文件**语法检查与差异检查通过。2.0.5 → 2.1.0 → 2.0.5 的 macOS、Linux 实际 npm 安装/升级/回滚均通过，每阶段 11 项持久性检查，演练前后持久文件一致。最终运行源码摘要为 `724dde5871900a9a06bcfe6f9ee45779517d7da31ba63cfb8c6f1da3515f8e6a`；正式部署使用同一版本的打包内容逐文件核验，私有部署报告单独保存。
